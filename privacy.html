Privacy Policy

ckboomc · Last updated September 30, 2026

What ckboomc is

ckboomc is a private app run by the owner of the YouTube channel ckboomc (@ckboomc). It generates videos and uploads them to that channel. It is not a public service and no one else signs in to it.

Google and YouTube data we access

With the channel owner's consent through Google OAuth, ckboomc uses the YouTube Data API to:

  • upload videos to the owner's own channel;
  • set thumbnails and manage playlists on that channel;
  • read the channel's basic information to confirm the upload goes to the right channel.

ckboomc does not collect, read or store data about any other YouTube or Google user.

How the data is stored and shared

The OAuth token is stored only on the owner's private server and is used only to perform the actions above. No Google user data is sold, shared with third parties, or used for advertising. ckboomc's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

ckboomc uses YouTube API Services. By using it you are bound by the YouTube Terms of Service, and the Google Privacy Policy applies.

Revoking access

Access can be revoked at any time from the Google Account third-party connections page. Revoking access stops all uploads; the stored token becomes unusable.

Contact

Questions about this policy can be sent through the issue tracker of this site.
